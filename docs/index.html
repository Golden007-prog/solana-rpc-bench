solana-rpc-bench

A Solana RPC benchmark you run from your own server

Compare Helius, QuickNode, Alchemy, Triton or the public endpoint from where your app runs: latency per method, errors and 429s, slot lag against the other endpoints, which heavier methods each one serves, and a WebSocket check. API keys are hidden in every output. Sequential and gentle. Zero dependencies.

One location, one time window. Latency includes your own network path to each provider. Not a ranking of providers.

What it measures

  • p50, p90 and max for getSlot, getLatestBlockhash, getBalance, getAccountInfo, getSignaturesForAddress and getTransaction
  • Errors, HTTP status counts, 429s and timeouts
  • Slot lag: every endpoint's slot read back to back, each round
  • Whether it serves getTokenLargestAccounts, filtered getProgramAccounts and getRecentPrioritizationFees (or your own list)
  • WebSocket open, slotSubscribe and first notification (Node 22+)
  • Text, --json or --markdown output

Use it in your code

npm install github:blixvip/solana-rpc-bench
import { bench, formatTable } from "solana-rpc-bench";

const report = await bench(
  ["https://api.mainnet-beta.solana.com", process.env.MY_RPC_URL].filter(Boolean),
  { rounds: 3, delayMs: 300, ws: false },
);
console.log(formatTable(report));
report.endpoints[0].methods.getAccountInfo.p50;   // ms
report.endpoints[0].slotLag.max;                  // slots behind the highest seen

Run it on a schedule or share a report

  • examples/github-action/bench.yml: copy into your repository's workflows to bench your endpoints daily from GitHub's runners, with the Markdown report in the job summary.
  • examples/html-report.js: turn --json output into one self-contained HTML page.

Full documentation, the API and the caveats are in the README. MIT licensed, no dependencies.
